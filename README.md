# Projeto de Aplicativo para Eventos

## Sobre o projeto

Este projeto tem como objetivo desenvolver uma plataforma digital para facilitar o acesso a informações e melhorar a comunicação durante eventos esportivos e outras atividades.

A aplicação pretende reunir informações importantes em um único lugar, permitindo que os participantes acompanhem notícias, agendas, boletins e avisos relacionados aos eventos.

Um dos principais diferenciais propostos é o desenvolvimento de uma solução de comunicação entre dispositivos móveis sem depender exclusivamente de uma conexão com a internet, buscando ampliar o acesso às informações em locais com conectividade limitada.

## Funcionalidades previstas

- **Notícias:** divulgação de informações e atualizações dos eventos.
- **Agenda:** consulta de datas, horários, locais e atividades programadas.
- **Boletins:** disponibilização de comunicados e informações oficiais.
- **Avisos:** divulgação de notificações importantes aos participantes.
- **Comunicação offline:** estudo e desenvolvimento de mecanismos de comunicação entre dispositivos próximos, mesmo sem acesso à internet.

## Objetivo

Desenvolver uma solução tecnológica acessível, funcional e expansível, que possa ser utilizada em diferentes tipos de eventos, facilitando a comunicação entre organizadores e participantes.

## Desenvolvimento

O projeto será desenvolvido colaborativamente por uma equipe de seis integrantes, com atividades distribuídas entre desenvolvimento da interface, comunicação entre dispositivos, lógica de rede, API, banco de dados, testes e integração.

## Status do projeto

🚧 Em desenvolvimento.

As funcionalidades descritas representam os objetivos planejados e poderão ser ajustadas durante o desenvolvimento.
